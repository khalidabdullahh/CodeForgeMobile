## 🌟 Overview

**CodeForge Mobile** is a full-featured, portable, phone-first coding environment designed to deliver a genuine desktop **VS Code** experience right in your pocket.

Whether you are traveling, on the couch, or building a prototype on your Android phone or tablet, CodeForge provides desktop-grade Monaco editing, an AI Copilot, offline Git source control, mobile quick-symbol keyboards, and live runtime previews.

👉 **Official Website & App Hub:** **[https://codeforgemobile.pages.dev](https://codeforgemobile.pages.dev)**

---

## 🚀 Key Features

- ⚡ **Monaco Editor Engine:** The exact same editor powering desktop VS Code with rich syntax highlighting, IntelliSense, parameter hints, and bracket pair colorization.
- 📱 **Mobile Quick Symbol Toolbar:** One-tap coding accessory bar with `{ }`, `( )`, `[ ]`, `<`, `>`, `=>`, `;`, `===`, `" "`, `' '`, `\``, `Tab`, `Undo`, and `Redo`.
- 🔄 **Landscape Mode Experience:** Turn your phone to landscape to unlock a true desktop VS Code layout with side-by-side split screen and docked terminal.
- 🤖 **AI Coding Copilot:** Integrated Google Gemini & OpenAI / DeepSeek assistant to explain code, fix bugs, and generate components directly into your active files.
- 🎨 **Multi-Theme Engine:** Switch seamlessly between **VS Code Dark**, **VS Code Light**, **Dracula**, **One Dark Pro**, **Monokai**, and **Synthwave '84**.
- 🖥️ **Live Interactive Preview & In-App Console:** Real-time web preview that captures `console.log`, `console.warn`, and `console.error` directly into the in-app terminal.
- 📴 **100% Offline PWA Ready:** Installable on Android, iOS, and Desktop as a standalone offline application.
- 📦 **One-Click Export:** Download your entire project workspace as a standard `.zip` file with zero configuration.
- 🤖 **Capacitor Android Packaging:** Pre-configured Capacitor settings ready to assemble native Android APK/AAB binaries with Android Studio.

## 💻 Local Development

To run CodeForge Mobile locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/khalidabdullahh/CodeForgeMobile.git
cd CodeForgeMobile

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open your browser at `http://localhost:5173`.

### Production Build

```bash
npm run build
```

---

## 📱 Android Build (Capacitor)

1. Build the web distribution:
   ```bash
   npm run build
   ```
2. Export the Capacitor configuration from within the app or use `android/capacitor.config.json`.
3. Open the project in Android Studio to build your `.apk` or `.aab` release.
