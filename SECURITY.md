# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in CodeForge Mobile, please do NOT create a public issue.

Instead, please report security issues privately by:
- Creating a **GitHub Private Vulnerability Report** in this repository (Security tab -> Report a vulnerability).
- Or emailing the maintainer directly at: `khalidabdullah.dev@gmail.com`

We appreciate your responsible disclosure and will address issues promptly.
